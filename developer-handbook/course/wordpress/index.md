# WordPress

WordPress powers a large share of the web, from single-author blogs to large
editorial platforms and enterprise sites. It combines a content management
system, a templating layer and a plugin architecture, which means "learning
WordPress" really means learning several separate systems that happen to ship
together.

This course covers WordPress as a development platform rather than as an
end-user product: how themes and plugins hook into the request lifecycle, how
data is modelled, and how to build on WordPress without fighting it.

## What this course will cover

- **Core architecture** — the request lifecycle, hooks, actions and filters.
- **Themes** — template hierarchy, template parts, and block themes.
- **Plugins** — structure, activation lifecycle, and safe extension points.
- **Data** — posts, post types, taxonomies, meta and the options API.
- **Security** — sanitisation, escaping, nonces and capability checks.
- **Performance** — caching layers, query tuning and asset loading.
