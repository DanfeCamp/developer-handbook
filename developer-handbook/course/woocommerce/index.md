# WooCommerce

WooCommerce turns WordPress into an e-commerce platform. It adds products,
carts, checkout, orders, payments and shipping on top of the WordPress core,
reusing the same hook system and data layer.

Because it builds directly on WordPress, this course assumes the
[WordPress course](/course/wordpress) as a starting point. The focus here is on
the commerce-specific parts: the order lifecycle, payment handling, and the
extension points you should use instead of editing core templates.

:::info Course in progress
This course is being written. Start with the
[WordPress course](/course/wordpress), which covers the platform fundamentals
these lessons depend on.
:::

## What this course will cover

- **Data model** — products, variations, orders, customers and coupons.
- **Order lifecycle** — cart, checkout, payment, fulfilment and refunds.
- **Templates** — safe overrides and the template hierarchy.
- **Payment gateways** — integrating and extending gateway classes.
- **Extending** — hooks, custom product types and the REST API.
- **Going live** — tax, shipping, performance and PCI considerations.
